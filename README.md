# element-quiz

周期表の空欄に元素記号と元素名を入力して、118元素を覚えるための Web ツールです。

**公開ページ:** https://nakaki84n.github.io/element-quiz/

- 紙に周期表の罫線を書かなくても、すぐに練習できます
- 答え合わせをすると、どこを間違えたかがひと目で分かります
- ログイン不要です。記録はブラウザの中だけに保存されます

## 使い方

### 1. 記号ターン

1. 周期表のマスに元素記号を入力します。
2. 「答え合わせ」を押します。

入力のしかた:

- 英字だけが入ります。1文字目は自動で大文字、2文字目は小文字になります（最大2文字）。
- PC では日本語入力がオンのままでも英字が入ります。
- 2文字入れると、自動で次のマス（原子番号順）に進みます。

### 2. 名前ターン

1. 記号ターンの結果画面で「名前ターンへ」を押します。
2. 元素名を入力して、「答え合わせ」を押します。

名前ターン中、記号欄には正しい元素記号が表示されます（「表示」で隠すこともできます）。

**英語名で答える:** 「表示」の「名前ターンの言語」を「英語」にすると、名前ターンが英語名ターンになります（ボタンも「英語名ターンへ」に変わります）。

- 英語名も元素記号と同じく、PC では日本語入力がオンのままでも英字が入ります。1文字目は自動で大文字になります。
- 名前ターンの途中で言語を変えた場合は、次の回から切り替わります（まだ何も入力していなければ、すぐ切り替わります）。

### 答え合わせの見方

| 結果 | 表示 | マスの色 |
|---|---|---|
| 正解 | ○ 自分の答え | 水色 |
| 不正解 | ✕ 自分の答え ／ 下の行に「→ 正解」 | 赤 |
| 未入力 | 未入力 ／ 下の行に「→ 正解」 | 点線の枠 |

下のバーに正答率が表示されます。

### 元素名の判定

文部科学省の表記どおりの元素名のほか、読みをひらがな・カタカナで書いても正解になります。
その元素を表す漢字として定着している別の表記（錫・珪素など）も正解です。

| 入力 | 判定 |
|---|---|
| 水素 ／ すいそ ／ スイソ | 正解 |
| ケイ素 ／ けい素 ／ けいそ ／ ケイソ ／ 珪素 ／ 硅素 | 正解 |
| スズ ／ すず ／ 錫 | 正解 |
| へりうむ | 正解（カタカナに直して比べる） |
| ほかの元素を表す漢字（例：ケイ素の欄に「錫」） | 不正解 |

正解とする別の漢字表記は次のとおりです（旧字体を含みます）。中国語の元素名（鈉・鈾など）は含みません。

| 元素 | 別の漢字表記 |
|---|---|
| ホウ素 (B) | 硼素 |
| フッ素 (F) | 弗素 |
| ケイ素 (Si) | 珪素、硅素 |
| リン (P) | 燐 |
| 硫黄 (S) | 硫黃 |
| 鉄 (Fe) | 鐵 |
| 亜鉛 (Zn) | 亞鉛 |
| ヒ素 (As) | 砒素 |
| スズ (Sn) | 錫 |
| ヨウ素 (I) | 沃素 |
| ビスマス (Bi) | 蒼鉛 |

全角・半角の違いと空白は無視します。

**英語名の判定:** 大文字・小文字は区別しません。IUPAC の表記（Aluminium、Caesium、Sulfur）のほか、別のつづり（Aluminum、Cesium、Sulphur）も正解です。

## 機能

| 機能 | 内容 |
|---|---|
| 全体／集中 | 「全体」は118元素すべてを出題します。「集中」では周期・族・ランタノイド・アクチノイドを選び、その範囲だけを出題します（複数選べます。表の周期・族の番号を押しても選べます）。集中モードのとき、ランタノイド・アクチノイドは周期・族の選択には含まれません。慣用名のある族は名前も表示します（1 アルカリ金属、2 アルカリ土類金属、15 プニクトゲン、16 カルコゲン、17 ハロゲン、18 貴ガス） |
| 表示 | 名前ターンの言語（日本語／英語）を選べます。次の2つもオン・オフできます：原子番号を表示する／名前ターン中に記号を表示する |
| 苦手マップ | 元素ごとの累計正答率を、周期表のマスの色で表示します。苦手なほど濃い赤になります。「記号｜名前｜英語名」で切り替えられ、マスにマウスを乗せるかタップすると成績が出ます |
| 履歴 | 答え合わせのたびに、日時・範囲・記号と名前の正答率を記録し、一覧で見られます（英語名で答えた回には「英」の印が付きます） |
| 最初から | 入力を消して最初からやり直します |
| 続きから再開 | 入力途中の内容・モード・範囲を自動で保存し、ページを閉じても続きから再開できます |

### キー操作（PC）

| キー | 動作 |
|---|---|
| Enter ／ Tab | 次のマスへ |
| Shift+Enter ／ Shift+Tab | 前のマスへ |
| ← → | 前後のマスへ（記号ターンのみ。名前ターンでは文字カーソルの移動） |
| ↑ ↓ | 同じ列の上下のマスへ |
| Backspace（空のマスで） | 前のマスへ |

日本語を変換している途中の Enter は、変換の確定として扱います（マスは移りません）。

### 画面の大きさ

- PC・タブレットでは、表が画面に収まるように自動で縮小します（下限70%）。
- スマホでは等倍のまま、表を横にスクロールして使います。

## 記録の保存について

記録はブラウザの localStorage に保存されます。

- 端末やブラウザが違うと、記録は共有されません。
- ブラウザのサイトデータを消すと、記録も消えます。
- 「履歴」の「履歴を消去」を押すと、履歴と苦手マップの記録がまとめて消えます。
- プライベートブラウズなど保存できない環境でも、練習自体はできます。

## 元素名の表記

元素名の表記は、文部科学省「一家に1枚周期表」第13版（2021年）に準拠しています。

https://www.mext.go.jp/stw/common/pdf/series/element/element_b13s.pdf

## 開発

Vite と TypeScript で作っています。UI ライブラリは使っていません。

```sh
npm install
npm run dev      # 開発サーバーを起動
npm run build    # 型チェックをして dist/ に出力
npm run preview  # ビルドしたものを確認
```

### ファイル構成

| ファイル | 内容 |
|---|---|
| `src/elements.ts` | 118元素のデータ（記号・元素名・読み・別の漢字表記・英語名・周期・族） |
| `src/table.ts` | 周期表とマスの組み立て |
| `src/main.ts` | 画面全体の動き（ターンの進行、入力、答え合わせ、モード切り替え、保存・復元） |
| `src/symbol.ts` | 元素記号の入力の整形 |
| `src/name.ts` | 元素名（日本語・英語）の正誤判定 |
| `src/range.ts` | 集中モードの範囲 |
| `src/storage.ts` | 記録と入力途中の内容の保存 |
| `src/history.ts` | 履歴の画面 |
| `src/heatmap.ts` | 苦手マップ |
| `src/settings.ts` | 表示設定 |
| `src/style.css` | 見た目（ダークモードのみ） |

### 公開

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）がビルドして GitHub Pages に公開します。

初めて公開するときだけ、リポジトリの Settings → Pages → Build and deployment の Source を「GitHub Actions」にしてください。
